# Изменения

## Подготовка публикации Vercel — 2026-10-11

- Добавлен `vercel.json` с командами установки/сборки PWA и каталогом `dist`.
- Явно указаны шаблоны исходников TypeScript и исключены каталоги сборок; проверка типов сохранена.
- Добавлен `GITHUB_UPLOAD.md` с составом исходников и инструкцией обновления существующего репозитория. Локально TS18003 не воспроизводится; удалённая структура требует проверки при загрузке.

## 0.2.0 — 2026-10-11

- Интерфейс переведён с Tauri/SQLite на IndexedDB; сохранены семь разделов, CRUD, оформление и импорт старых JSON-копий.
- Добавлены Service Worker, статический офлайн-кэш, манифест, иконки установки и адаптация для телефона.
- Системные уведомления перенесены на браузерный API с явным описанием ограничений закрытого приложения; журнал доставки хранится в IndexedDB.
- Реализована защита от перезаписи данных устаревшей вкладкой. Тесты используют настоящее браузерное хранилище и проверяют полный перезапуск офлайн.

## 0.1.0 — 2026-10-11

- Реализованы семь разделов личного планировщика, локальное хранение, валидация и миграция SQLite.
- Добавлены Rust-планировщик, системные уведомления, трей и ограничение одного экземпляра.
- Добавлены JSON-резервные копии, редактируемые примеры и локальные цитаты с источниками.
- Добавлены проверки денег/дат, SQL-хранилища, Rust Store и сценариев интерфейса. Ограничения фактической проверки описаны в VERIFICATION.md.
