# Not Give Up — PWA

Личный офлайн-планировщик на React + TypeScript. Все семь разделов сохранены: расписание, тренировки, финансы, проекты, цели, напоминания и настройки. Данные находятся в IndexedDB браузера, интерфейс и ресурсы кэширует Service Worker. Аккаунт, API, серверная база, Rust, Tauri и SQLite для запуска больше не нужны.

## Запуск

Нужен Node.js 22.12+; проверено на Node.js 24.21.0 и npm 11.19.0.

```powershell
npm ci
npm run build
npm run preview
```

Откройте **http://localhost:4173**. Готовые файлы — `dist/`. Для разработки: `npm run dev` (порт 1420). Service Worker включён только в production-сборке, поэтому офлайн-режим проверяйте через `preview`.

## Установка на телефон и ПК

1. Разместите содержимое `dist/` на любом статическом HTTPS-хостинге, сохранив структуру файлов. Публикация в этой задаче не выполнялась. Собственный сервер приложения или API не нужен.
2. Откройте HTTPS-адрес на телефоне. Дождитесь надписи «Готово к работе без интернета» в настройках.
3. Android / ПК: кнопка «Установить приложение», если браузер её предлагает, либо меню браузера → «Установить приложение» / «Добавить на главный экран».
4. iPhone / iPad: Safari → «Поделиться» → «На экран Домой».

После первого открытия и подготовки кэша приложение запускается без сети, включая перезапуск браузера. Первое получение файлов требует сети. Обычный HTTP по IP компьютера в локальной сети не обеспечивает установку PWA: нужен HTTPS; исключение для разработки — localhost на том же устройстве. Не запускайте `dist/index.html` через `file://`.

## Данные и совместимость

- IndexedDB `not-give-up`, версия 1: `state` — данные и ревизия, `deliveries` — журнал уведомлений.
- Запись атомарная; интерфейс подтверждает её после завершения транзакции. Старая вкладка не может молча перезаписать более новую ревизию.
- Даты расписания — локальные календарные строки; напоминания — UTC с показом местного времени. Деньги — целые копейки, без округления ввода.
- JSON-копии старой desktop-версии импортируются: все сущности и настройки оформления сохраняются; настройка трея больше неприменима и удаляется из копии.
- Экспорт использует скачивание файла браузером; импорт — выбор JSON, валидацию и подтверждение замены. Повреждённый файл не меняет данные.
- Данные отдельные для каждого устройства, браузера и адреса сайта. Синхронизации нет. Переносите их через JSON. Автоматического чтения прежнего SQLite-файла нет.
- Очистка данных сайта удаляет локальную базу. В настройках можно запросить постоянное хранение (решение принимает браузер); это не заменяет резервные копии.
- Примеры расписания и тренировок создаются один раз при инициализации, редактируются и удаляются.

## Напоминания

Раздел сохранён. Кнопка проверки запрашивает разрешение и вызывает настоящий `ServiceWorkerRegistration.showNotification`. Планировщик проверяет время каждые 15 секунд при открытом приложении, а также при возврате фокуса. Запись о передаче уведомления системе сохраняется в IndexedDB; после перезапуска оно не повторяется. Измените время для нового срабатывания.

**При полностью закрытом приложении точные локальные уведомления без сервера недоступны.** Браузер также может приостанавливать таймеры в фоне. Пропущенные напоминания обрабатываются после открытия при наличии разрешения. На iPhone доступность зависит от версии iOS и запуска с экрана Домой. Трей и Windows-служба в PWA отсутствуют. Баннеры могут скрываться настройками ОС. Отправка системному API не означает, что пользователь увидел уведомление.

## Сборка и обновления

`npm run build` генерирует `dist/sw.js` с перечнем и версией всех статических ресурсов. Обновлённый Service Worker активируется после закрытия старых вкладок приложения; данные IndexedDB не удаляются. Приложение можно размещать и в подкаталоге: пути относительные, кэш ограничен путём установки. Желательно отдавать `sw.js`, манифест и `index.html` с перепроверкой кэша (`Cache-Control: no-cache`), а хешированные файлы `assets/` — с длительным кэшированием.

## Проверки

```powershell
npm test
npm run build
npm run test:ui
```

Браузерные тесты используют установленный Microsoft Edge, настоящие IndexedDB и Service Worker. Тест системного уведомления подменяет только API показа баннера, проверяя планировщик и реальный журнал доставки. Отчёт — [VERIFICATION.md](VERIFICATION.md).

Исходники предыдущей нативной версии `src-tauri/` и старый SQL-тест оставлены как история реализации; они не входят в npm-команды, зависимости или PWA-сборку.
