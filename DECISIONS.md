# Решения

## 0.2.0 — переход на PWA по запросу пользователя

- React + TypeScript сохранены; нативные зависимости исключены из интерфейса и npm-сборки. Tauri/Rust/SQLite больше не требуются. Исходники desktop-версии сохранены, но не используются.
- IndexedDB хранит атомарный снимок данных с номером ревизии. Проверка ревизии внутри транзакции защищает от потери изменений при работе в нескольких вкладках. Отдельное хранилище содержит журнал доставки.
- Полная проверка данных перенесена из Rust в TypeScript; поддерживается импорт старых JSON-копий схемы 1. Трей неприменим к PWA и удалён из актуальных настроек.
- Service Worker кэширует только локальные статические ресурсы; список и версия создаются при сборке без дополнительного PWA-фреймворка. Обновления ждут закрытия старых вкладок и не удаляют пользовательскую базу.
- Без серверной push-инфраструктуры уведомления по расписанию гарантировать после закрытия PWA нельзя. Приложение честно описывает ограничения; при открытом окне использует системный API, сохраняет журнал и обрабатывает пропущенные записи.
- Данные не синхронизируются: перенос через JSON. Деньги остаются целыми копейками, календарные даты — локальными строками, напоминания — UTC.
- Внешняя публикация не выполнялась; результат — локальная статическая сборка для HTTPS-хостинга.
